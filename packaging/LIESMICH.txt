MEINE KASSE – Hinweise für den Testbetrieb
==========================================

Starten
-------
Doppelklick auf  MeineKasse.exe  in diesem Ordner. Es ist keine Installation und kein Python
nötig. Der gesamte Ordner "MeineKasse" gehört zusammen (nicht nur die EXE kopieren).

Beim ersten Start legen Sie den ersten Anwender mit einem erstmaligen Passwort an. Dieses
müssen Sie bei der ersten Anmeldung ändern.

Windows meldet beim ersten Start unter Umständen "Der Computer wurde durch Windows geschützt"
(SmartScreen), weil die Anwendung nicht signiert ist. Mit "Weitere Informationen" und
"Trotzdem ausführen" starten Sie sie.

Wo liegen meine Daten?
----------------------
Die Daten liegen im Unterordner "Daten" neben MeineKasse.exe:

    Daten\meine_kasse.sqlite     (Datenbank)
    Daten\logs\meine_kasse.log   (Protokoll bei Fehlern)

Im Programm zeigt  Hilfe > Über Meine Kasse  die genauen Pfade.

Jede Kopie des Programmordners hat damit ihre eigene Datenbank. Kopieren Sie den Ordner
(ohne den Unterordner "Daten") an einen neuen Ort, startet dort eine leere Kasse mit
erstmaliger Passwortvergabe. Kopieren Sie den Ordner MIT "Daten", erhalten Sie einen Klon
der bestehenden Kasse.

Mehrere Kassen
--------------
Beispiel:  C:\Kassen\Privat\MeineKasse.exe  und  C:\Kassen\Verein\MeineKasse.exe  verwalten
vollständig getrennte Daten.

Datensicherung
--------------
Im Programm:  Datei > Datensicherung erstellen...
Es wird eine vollständige, geprüfte Kopie der Datenbank als .sqlite-Datei geschrieben. Die
erzeugten PDF-Dateien (Ordner "Daten\Dokumente") werden in den Ordner "<Name>_Dokumente"
neben der Sicherungsdatei kopiert. Sichern Sie vor jedem Update und regelmäßig. Bewahren Sie
die Sicherung (Datei UND Dokumentenordner) an einem anderen Ort auf (z. B. USB-Stick).

Wiederherstellen
----------------
1. Programm beenden.
2. Die Sicherungsdatei in den Ordner "Daten" kopieren und in  meine_kasse.sqlite
   umbenennen (die vorhandene Datei vorher zur Seite legen). Den Dokumentenordner der
   Sicherung als "Daten\Dokumente" zurückkopieren.
3. Programm starten.

Update auf eine neue Version
----------------------------
1. Datensicherung erstellen.
2. Programm beenden. Im alten Ordner alles AUSSER dem Unterordner "Daten" durch den Inhalt
   des neuen Ordners ersetzen (den Ordner "Daten" nicht löschen!).
3. Starten. Die Datenbank wird beim Start automatisch auf den neuen Stand gebracht.

Testen mit getrennten Daten (ohne die echten Daten zu berühren)
---------------------------------------------------------------
Mit der Umgebungsvariable MEINE_KASSE_DB können Sie eine andere Datenbankdatei verwenden:

    set MEINE_KASSE_DB=C:\Temp\kasse_test\test.sqlite
    MeineKasse.exe

Löschen Sie diese Datei, um wieder bei null zu beginnen.

Deinstallation
--------------
Den Ordner "MeineKasse" löschen. Damit werden auch die Daten entfernt (vorher sichern!).
Daten einer früheren Version liegen ggf. noch unter %LOCALAPPDATA%\MeineKasse.

Bei Fehlern
-----------
Meldet das Programm einen unerwarteten Fehler, steht die Ursache in der Protokolldatei (Pfad
siehe oben). Bitte diese Datei mitschicken. Sie enthält keine Passwörter.
